存在较明显的疑似错配，例如：

| 岳麓书院 | 内蒙古·呼伦贝尔 | 景点名称与地域疑似不匹配 |
| 厦门大学 | 福建·南平·武夷山市 | 景点名称与城市疑似不匹配 |
| 永定土楼群 | 天津市·滨海新区 | 景点名称与地域疑似不匹配 |

**影响：**

- 地图可视化和距离计算不可靠；
- 地域偏好、交通方式与目的地的关联分析会被污染；
- 同一景点可能被错误归入其他省份。

### 2. 景点类别存在错分类

| 植物园、动物园、温泉度假区 | 类型分布不统一 | 建议增加二级分类 |

建议将类别体系调整为：

- 自然景观
- 历史遗迹
- 人文景观
- 主题公园
- 博物馆
- 动物园/植物园

- 运动及户外体验

### 3. 评分分布疑似异常

从记录观察：

- 大量评分集中在 **1.0—2.0 分**；
- 存在 `0.5`、`0.6`、`0.8` 等低分；
- 高于 4 分的景点较少；
- 个别景点的名称、热度和评分组合不符合通常平台评价规律。

例如：

| 景点 | 评分 | 热度 |

| 太湖鼋头渚 | 4.4 | 4,639 |

**判断：**

> 当前 `rating` 很可能不是常见的 5 分制用户综合评分，或者存在字段映射、缩放、抽样、接口采集或反向评分问题。暂不宜直接把它解释为游客满意度。

## 2. 景点主题聚类

### 主题一：文化深度游

**核心特征：**

- 类型：历史遗迹、历史遗址、人文景观；
- 标签：文化古迹、古建筑、考古价值、历史科普、文物展览；
- 价格：从免费到中高价均有；
- 代表景点：布达拉宫、秦始皇兵马俑博物馆、殷墟博物院、大雁塔、敦煌莫高窟。

**商业含义：**

> 该主题的核心不是门票价格，而是文化解释能力。讲解员、数字展陈、沉浸式导览和文创商品比单纯涨价更可能提升客单价。

### 主题二：自然探索游

**核心特征：**

- 类型：自然景观；
- 标签：自然风光、山水风光、生态休闲、户外徒步、摄影天堂；
- 代表景点：洱海、喀纳斯湖、桂林漓江、天山天池、稻城亚丁。

**商业含义：**

> 自然类产品适合围绕季节、摄影、徒步、自驾和户外装备建立产品组合，而不是只销售门票。

### 主题三：亲子欢乐游

**核心特征：**

- 类型：主题公园；
- 标签：家庭出游、亲子友好、娱乐刺激、沉浸式、主题体验；
- 代表景点：香港迪士尼、北京欢乐谷、香港海洋公园、罗蒙环球乐园。

**商业含义：**

> 亲子客群关注的不只是景点本身，还关注排队时间、儿童餐饮、休息区、卫生设施和安全服务。

### 主题四：城市文化漫游

**核心特征：**

- 类型：人文景观；
- 标签：文化体验、传统民俗、人文历史、艺术鉴赏；
- 价格：免费或低价比例较高；
- 代表景点：夫子庙秦淮风光带、维多利亚港、九份老街、田子坊创意街区。

**商业含义：**

> 适合发展城市步行路线、夜游、餐饮联动、文创消费和短途周末产品。

### 主题五：高价综合体验

**核心特征：**

# 四、建议的精确计算代码

以下代码可生成价格、类别、评分、热度和地域统计结果：

```python
import json
import numpy as np
import pandas as pd

# 解析
spots = json.loads(raw_json_string)
df = pd.DataFrame(spots)

# 数值字段清洗
for col in ["base_price", "rating", "total_visits"]:
    df[col] = pd.to_numeric(df[col], errors="coerce")

# 基础统计
price_summary = df["base_price"].describe()
rating_summary = df["rating"].describe()
visit_summary = df["total_visits"].describe()

# 价格区间
price_bins = [-np.inf, 50, 100, 200, 300, np.inf]
price_labels = ["0-50", "50-100", "100-200", "200-300", "300+"]
df["price_band"] = pd.cut(
    df["base_price"],
    bins=price_bins,
    labels=price_labels,
    right=False
)

price_distribution = (
    df.groupby("price_band", observed=False)
      .agg(
          count=("spot_id", "count"),
          avg_price=("base_price", "mean"),
          avg_rating=("rating", "mean"),
          avg_visits=("total_visits", "mean")
      )
)

# 类别统计
type_summary = (
    df.groupby("type")
      .agg(
          count=("spot_id", "count"),
          avg_price=("base_price", "mean"),
          median_price=("base_price", "median"),
          avg_rating=("rating", "mean"),
          total_visits=("total_visits", "sum")
      )
      .sort_values("count", ascending=False)
)

# 热度 Top 10
top10_visits = (
    df.sort_values("total_visits", ascending=False)
      [["spot_id", "name", "province", "type",
        "base_price", "rating", "total_visits"]]
      .head(10)
)

# 地域统计
province_summary = (
    df.groupby("province")
      .agg(
          count=("spot_id", "count"),
          avg_price=("base_price", "mean"),
          avg_rating=("rating", "mean"),
          total_visits=("total_visits", "sum")
      )
      .sort_values("count", ascending=False)
      .head(10)
)

# 相关性
correlation = df[
    ["base_price", "rating", "total_visits"]
].corr(method="spearman")

# 热度对数变换后的相关性
df["log_visits"] = np.log1p(df["total_visits"])
log_corr = df[
    ["base_price", "rating", "log_visits"]
].corr(method="spearman")

# 评分异常检测
rating_distribution = (
    df["rating"]
    .round(1)
    .value_counts()
    .sort_index()
)

# 0 元价格检查
zero_price = df[df["base_price"] == 0]

# 地理质量初筛
geo_suspects = df[
    df["city"].isna()
    | df["province"].isna()
    | df["coordinates"].isna()
]
```

# 五、总体结论

1. **当前景点数据覆盖自然、人文、历史和主题娱乐等多种旅游场景，具有较强的产品组合价值。**
2. **价格从免费到 600 元，消费层次完整，但存在明显长尾和高价异常点。**
3. **热度与价格、评分没有明显同步关系，部分低评分景点反而拥有极高访问量。**
4. **评分字段存在严重低分聚集现象，建议在业务分析中暂不直接作为满意度指标。**
5. **地域和类别字段存在明显错配，必须先完成地理校验与分类标准化。**
6. **主题公园适合亲子和家庭产品，自然景观适合摄影、徒步和自驾产品，历史人文景点适合讲解、研学和城市漫游产品。**
7. **由于缺少 `user_itinerary` 和 `raw_reviews`，当前无法完成真正意义上的用户聚类、季节趋势分析、评论情感分析和三类数据交叉验证。**
8. **在补充用户行程、评论和游记数据后，建议重新计算完整报告，并将异常地域、错分类景点和评分异常记录单独建表处理。**
